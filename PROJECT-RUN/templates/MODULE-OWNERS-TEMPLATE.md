## 6. 使用约定

- **Owner 变更**：更新本表并追加一行到本文档末尾的变更记录（含日期）。
- **备份 Owner**：主 Owner 请假 / 24 小时未响应时，备份接管；备份不接管日常评审，只在 P0 场景启用。
- **Owner ≠ 唯一写权限**：CODEOWNERS 触发 review，但代码合入仍由 branch protection 把关。
